# Plan — Matricule National & Paiements MINESEC

## 0. Contexte & décisions clés

### Réalité métier confirmée
- **Frais de scolarité + examens** → paiement OBLIGATOIRE via cartescolaire.cm (MINESEC). EduNexus **ne collecte jamais** cet argent, il ne fait que **vérifier/reflecter** le paiement.
- **Frais établissement** (APE, cantine, uniforme…) → paiement via CampPay (EduNexus collecte). Le système FeePlan/Facture/Payment existant gère déjà ça.
- **Matricule national** : identifiant unique de chaque élève du secondaire. Sans matricule = pas de paiement MINESEC, pas d'inscription examen.

### Décisions d'architecture
1. **Approche hybride** cartescolaire.cm : scraping en priorité + saisie manuelle en secours + affichage clair de la source (vérifié auto vs saisi manuellement)
2. **Deux modules séparés** : PaiementMinesec (nouveau, vérification) ≠ FeePlan/Facture/Payment (existant, collection)
3. **Priorité** : import matricules Excel d'abord → suivi paiements ensuite
4. **Fusion avec import existant** : l'import élèves actuel (`ImporterUtilisateursUseCase`) a déjà un champ `matricule` dans `ImportRow` (non utilisé) et `StudentProfile.matricule` existe dans le schéma. On enrichit l'import existant plutôt que de créer un 3ème mécanisme.

### Fichiers existants réutilisables
| Fichier | Champ existant | Usage |
|---|---|---|
| `StudentProfile.matricule` (schema.prisma:315) | `String?` | Déjà présent, à alimenter |
| `ImportRow.matricule` (ImporterUtilisateursUseCase.ts:11) | `string?` | Déclaré mais non traité → à traiter |
| `FeePlan` / `Invoice` / `Payment` (schema.prisma:925-990) | existant | Frais établissement → ne pas toucher |
| `CampayPaiementService` | existant | Paiement établissement → ne pas toucher |

## Phase 2 — Import matricules Excel (priorité)

### 2.1 Un seul use case : `ImporterMatriculesUseCase`

**Un seul mécanisme** qui gère les deux formats de fichier (détection auto via en-têtes de colonnes) :

| Format | Colonnes détectées | Usage |
|---|---|---|
| **Format ZekoulABia** | nom, prenom, classe, LV2, PEBS, matricule… | Import élèves complet (matricule = colonne optionnelle) |
| **Format cartescolaire.cm** | Nom, Prénom, Date Naissance, Établissement, Matricule | Import dédié matricules MINESEC |

**Logique commune** :
1. Parser le fichier (détection format via en-têtes)
2. Pour chaque ligne : matcher l'élève par (nom + prénom + dateNaissance) dans ZekoulABia
3. Si trouvé ET pas de matricule → mettre à jour `StudentProfile.matricule` + `matriculeSource: 'EXCEL_IMPORT'`
4. Si trouvé ET matricule différent → flag CONFLICT
5. Si non trouvé → marquer UNMATCHED (à traiter manuellement)
6. Créer un `MatriculeImportJob` avec stats détaillées

**Réutilisation** : le parser Excel existant (xlsx, déjà dans le projet) + le pattern d'import déjà établi dans `ImporterUtilisateursUseCase`.

## Phase 3 — Vérification cartescolaire.cm (hybride)

### 3.1 Architecture

```
CarteScolaireAdapter (port)
  ├── CarteScolaireScrapingAdapter (cheerio, cache, circuit breaker)
  └── CarteScolaireManualAdapter (saisie admin)
```

### 3.2 Scraping adapter

- **Technologie** : cheerio + fetch (déjà dans le projet)
- **Cache** : TTL 4h pour vérifications matricule, 30min pour statuts paiement
- **Rate limiting** : max 1 requête/500ms
- **Circuit breaker** : 5 erreurs consécutives → pause 30min + alerte
- **User-Agent** : navigateur standard
- **Fallback** : si scraping échoue → status "NON_VERIFIE" + lien direct cartescolaire.cm

### 3.3 Flux clarifié IMPAYE → PAYE → VERIFIE

```
Enrollment créé
  → PaiementMinesec générés en statut IMPAYE

Admin déclare un paiement (parent présente reçu)
  → Saisie numéro reçu via endpoint verify-recu
  → Statut : IMPAYE → PAYE (confiance admin, source = MANUAL)
  → dataSource = MANUAL

Vérification cartescolaire.cm (scraping ou sync nocturne)
  → Paiement confirmé sur cartescolaire.cm
  → Statut : PAYE → VERIFIE (source = SCRAPE_AUTO ou SYNC_NIGHTLY)
  → recuVerifie = true, recuVerifieAt = now()

Si scraping échoue :
  → Statut reste PAYE (admin a confirmé, pas de preuve en ligne)
  → Lien direct vers cartescolaire.cm pour vérification manuelle
```
